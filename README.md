## 📁 File Naming Convention

Files follow the standard Codeforces problem naming scheme:

```
<contest_id><problem_letter>.<extension>
```

**Examples:**
- `1234A.py` → Contest 1234, Problem A
- `2200E.py` → Contest 2200, Problem E  
- `1547F.cpp` → Contest 1547, Problem F (solved in C++)

**Special suffixes you might see:**

| Suffix | Meaning |
|--------|---------|
| `- fail` | Incorrect solution — kept for reference |
| `- tle` | Time Limit Exceeded — kept for reference |
| `- wa` | Wrong Answer attempt |
| `- dnf` | Did Not Finish during contest |
| `- redo` / `- again` | Revisited and re-solved later |

- Files with `- fail` or `- tle` suffixes are intentionally kept — they're useful for understanding what *doesn't* work.
- Some problems have both a `.py` and a `.cpp` version, check both for maybe a different implementation or due to problem constraints.
